# Factory Pulse

Symulowany dashboard monitoringu maszyn produkcyjnych w czasie rzeczywistym.

Projekt portfolio łączący doświadczenie w Industry 4.0 z umiejętnościami
fullstack (React, TypeScript, Node.js). Symulowane maszyny wysyłają dane
przez MQTT (Node-RED), backend odbiera je i przesyła do frontendu przez
WebSocket, gdzie prezentowane są na żywo: stan pracy, przestoje, alarmy.

## Cel
Nauka integracji IT-OT (MQTT, OPC UA) oraz budowy aplikacji real-time.

## Stack
- Frontend: React 19, TypeScript, Vite
- Backend: Node.js
- Integracja: MQTT (Node-RED), WebSocket
- (planowane: OPC UA, baza danych, Docker)
